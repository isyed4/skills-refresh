# skills-refresh

Functions are used to prevent repetitive code, they are chunks of code that can be called upon later without rewriting the whole code of the function

Variables that exist within the function do not exist outside of the function. 

Variables that are declared outside the function can be called in newly created functions

You can also modify outer variables inside the function

Local variable = inside the function
outer variable = outside the function ~ also called Global variables

Parameters = we can arbitrary data to functions using parameters
Argumen = An argument is the value that is passed to the parameter when called
